# مؤشر وزاري موحد - PressGaney

## 📋 نظرة عامة

تم إضافة ميزة المؤشر الوزاري الموحد لنظام PressGaney. تسمح هذه الميزة بإدخال وحفظ مؤشر وزاري موحد لكل رحلة وسنة وربع، مع عرضه في الرسم البياني.

## 🗄️ قاعدة البيانات

### إنشاء الجدول

قم بتشغيل ملف SQL التالي في القاعدة المركزية (`hospitals_mecca3`):

```sql
-- ملف: backend/sql/create_pressganey_moh_targets.sql
```

الجدول: `pressganey_moh_targets`

### البنية

- `TargetID`: معرف فريد
- `TripName`: اسم الرحلة (مثل: "العيادات")
- `Year`: السنة (مثل: 2025)
- `Quarter`: الربع (Q1, Q2, Q3, Q4)
- `TargetScore`: المؤشر الوزاري (0-100)
- `CreatedBy`: معرف المستخدم
- `CreatedAt`, `UpdatedAt`: تواريخ الإنشاء والتحديث

**مفتاح فريد**: `(TripName, Year, Quarter)` - يضمن مؤشر واحد فقط لكل رحلة + سنة + ربع

## 🔌 APIs

### 1. حفظ/تعديل المؤشر

**POST** `/api/pressganey/moh-target`

**Body:**
```json
{
  "tripName": "العيادات",
  "year": 2025,
  "quarter": "Q3",
  "targetScore": 80
}
```

**Response:**
```json
{
  "ok": true,
  "message": "تم حفظ المؤشر الوزاري بنجاح",
  "data": {
    "tripName": "العيادات",
    "year": 2025,
    "quarter": "Q3",
    "targetScore": 80
  }
}
```

### 2. جلب المؤشر

**GET** `/api/pressganey/moh-target?tripName=العيادات&year=2025&quarter=Q3`

**Response:**
```json
{
  "ok": true,
  "data": {
    "targetID": 1,
    "tripName": "العيادات",
    "year": 2025,
    "quarter": "Q3",
    "targetScore": 80,
    "createdBy": 1,
    "createdAt": "2025-01-01T00:00:00.000Z",
    "updatedAt": "2025-01-01T00:00:00.000Z"
  }
}
```

## 🎨 الواجهة

### 1. واجهة الإدخال

تظهر في قسم "مقارنة الرحلات بين جميع المستشفيات" وتحتوي على:
- اختيار الرحلة
- اختيار السنة
- اختيار الربع
- إدخال المؤشر (0-100)
- زر الحفظ

### 2. كارد العرض

يعرض:
- **المؤشر الوزاري**: القيمة المحفوظة
- **نتيجة المستشفى**: المتوسط الحالي
- **الفرق عن المؤشر**: الفرق بين النتيجة والمؤشر
- **التغير عن الربع السابق**: نسبة التغير بالمئة

### 3. الرسم البياني

- يظهر خط أحمر متقطع يمثل المؤشر الوزاري
- الخط يظهر فوق الأعمدة في الرسم البياني
- نفس تصميم تقارير الوزارة
